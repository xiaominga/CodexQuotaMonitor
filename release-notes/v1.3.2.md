## 更新内容

- 增强托盘额度环在深色、浅色任务栏中的辨识度，保留绿色、黄色、红色的额度含义和原有阈值。
- 放大双环并统一底环、进度弧与无数据圆弧的线宽和半径，移除进度弧下方重叠的底环，减少灰色透边。
- 额度耗尽时，对应圆环变色并显示中心短杠。
- 无数据状态改为居中位于上、下、左、右的四段等长圆弧，避免虚线周期造成不对称。
- 补充深浅主题、不同尺寸、颜色对比度、边缘像素和无数据对称性的渲染回归验证。

## 下载与升级

- 安装版：下载 `CodexQuotaMonitor-Setup-1.3.2.msi`，退出正在运行的旧版后安装。
- 便携版：下载 `CodexQuotaMonitor.Wpf.exe`，退出旧版后替换 EXE。
- 两种方式都包含 .NET 运行时，适用于 Windows 10/11 x64，无需单独安装 .NET。
- `SHA256SUMS` 提供 EXE 和 MSI 的 SHA256 校验值。

本版本未使用商业代码签名证书，首次运行可能出现 Windows SmartScreen 提示。
