## 更新内容

- 增加动态托盘额度环：内圈显示 5H，外圈显示周额度，支持剩余比例、阈值颜色和无数据状态。
- 增加可开关并保存的玻璃装饰效果，优化紧凑数字布局和刷新状态提示。
- 卡片圆角、玻璃装饰和托盘额度环改用 WPF 原生矢量绘制与抗锯齿。

## 下载与升级

- 安装版：下载 `CodexQuotaMonitor-Setup-1.3.0.msi`，退出正在运行的旧版后安装；沿用原产品的升级标识。
- 便携版：下载 `CodexQuotaMonitor.Wpf.exe`，退出旧版后替换 EXE。
- 两种方式都包含 .NET 运行时，适用于 Windows 10/11 x64，无需单独安装 .NET。
- `SHA256SUMS` 提供两个安装产物的 SHA256 校验值。

本版本未使用商业代码签名证书，首次运行可能出现 Windows SmartScreen 提示。
