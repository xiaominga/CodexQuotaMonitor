## 更新内容

- 调整发布流程：仅推送新版本标签时在 GitHub 云端测试、打包和生成 Release 草稿，普通分支推送及 PR 不再触发构建。
- EXE、MSI 与版本标签保持一致，提供 SHA256 校验文件。

本版本包含相较 v1.2.0 新增的动态托盘额度环、可选玻璃装饰效果、紧凑数字布局和刷新状态提示，以及卡片圆角、玻璃装饰和托盘额度环的 WPF 原生矢量绘制与抗锯齿。

## 下载与升级

- 安装版：下载 `CodexQuotaMonitor-Setup-1.3.1.msi`，退出正在运行的旧版后安装；沿用原产品的升级标识。
- 便携版：下载 `CodexQuotaMonitor.Wpf.exe`，退出旧版后替换 EXE。
- 两种方式都包含 .NET 运行时，适用于 Windows 10/11 x64，无需单独安装 .NET。
- `SHA256SUMS` 提供 EXE 和 MSI 的 SHA256 校验值。

本版本未使用商业代码签名证书，首次运行可能出现 Windows SmartScreen 提示。
